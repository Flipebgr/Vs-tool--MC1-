# Tenant Thread Visual Analytics

## VAST Challenge 2026 - Mini Challenge 2

Ferramenta de Visual Analytics desenvolvida para a disciplina de **Visualização da Informação**.

O objetivo é analisar os dados do **VAST Challenge 2026 - Mini Challenge 2**, permitindo explorar visualmente a estrutura organizacional da empresa Tenant Thread e reconstruir a sequência de eventos responsável pela postagem anômala realizada no SaidIT.

---

## Objetivos

- Explorar o organograma da Tenant Thread
- Analisar relações entre pessoas, departamentos, agentes e sistemas
- Explorar a linha temporal dos eventos
- Reconstruir automaticamente a cadeia da postagem
- Auxiliar na resposta das perguntas do desafio
